# R1 text and voice task routing

The existing text composer and Whisper transcript path now recognize a deliberately small set of complete TR/EN/DE commands (analyze this file, make the chart green, and documented equivalents). Other normal messages continue through the original chat path. The explicit Task:/Görev:/Aufgabe: prefix opts into a one-shot Jan proposal for broader wording. The proposal must be a strict JSON object selecting analyze, recolor (enumerated color), or unsupported. Duplicate/extra keys, model-supplied paths/artifact IDs, shell commands, markup and malformed outputs are refused. This is a bounded prototype, not general natural-language computer control.

For the explicit model route only the user's submitted request and a fixed classifier instruction reach the configured loopback endpoint. Never send the selected file contents, discovered path, prior chart, artifact ID, summary or conversation history to the classifier. Loopback alone does not prove an external server never uses upstream providers; actual Jan configuration remains an owner verification gate. The picker alone grants the selected source, and analysis is gated to LOCAL_ONLY. A voice or model proposal never grants file access by itself.

Analysis intent opens the native picker once the preceding turn has drained. A follow-up recolor uses the current session's last authorized artifact. Selected-file computation and recolor share the controller worker, and summaries are derived from deterministic results, not LLM-generated numbers. The existing local Piper path is invoked with the appropriate language voice when configured and permitted; mute/stop-speaking/cancel/hard-stop are respected. Missing/denied speech leaves the chart visible and reports the speech limitation. Optional spoken text is contained in the revocable artifact widget rather than model conversation history.

Eight core and six GTK fixture tests added. They exercise bounded intents, privacy of classifier input, rejection, typed and transcribed chart follow-ups and synthetic playback. The tests use fake Jan/Whisper/Piper services and explicit trusted fixture selection, not the owner's physical microphone or file chooser acceptance. Actual service readiness, natural-language coverage beyond the small route, real playback, export and owner COSMIC crash reproduction remain open. No auto-merge.
