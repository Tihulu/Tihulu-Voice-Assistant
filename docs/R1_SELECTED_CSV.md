# R1 selected CSV snapshot

The trusted local file picker/controller (not a model tool) calls the reader with a selected absolute path, a live authorization callback and cancellation callback. The helper requires an explicit true authorization, rechecks between operations and before return, and does not grant permissions itself. R1 integration must bind this callback to the actual session/task, selected source, active LOCAL_ONLY mode and profile; never use a permissive default or expose a pathname argument to a model.

Linux descriptor-relative traversal refuses dot segments and symlinks, uses O_PATH to pin a regular inode before opening for read, then reads the pinned inode via procfs with a 256 KiB budget. Rejects nonregular files, detectable mutation and short reads; closes descriptors; returns immutable bytes, not a path. No output writes or network. No guarantee of identity before pathname resolution, no hardlink/mount namespace isolation, and no protection against a compromised OS. A portal-supplied open descriptor can strengthen the selection contract later. Do not use this helper as a general sandbox or claim arbitrary filesystem security. Live policy checks must also occur before artifact publication; revocation cannot retroactively undo bytes already read.

Existing text attachment handling is not replaced in this increment. Its path-based stat/read and truncation contract differs from a scientific snapshot; the new analysis route must not pass raw CSV through the chat prompt. The existing profile policy requires a separate audit: absent-rule behavior of require_tool is not a strict grant, and effective CLOUD_CHAT does not yet exclude all file actions. R1 must use an explicit LOCAL_ONLY gate and a scoped grant before invoking this reader. Repair the wider mode contract with regression tests before enabling additional modes.

Tests use temporary synthetic files only. Coverage includes explicit authorization, symlink and nonregular rejection, size limits, source immutability, detectable mutation, cancellation, revocation and short reads. Unit tests alone do not prove the GTK picker works or that the controller enforces policy. Owner picker crash remains UNKNOWN/HOLD.
