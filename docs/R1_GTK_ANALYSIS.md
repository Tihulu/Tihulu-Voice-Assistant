# R1 native local analysis view

Stacked on #83. The conversation view now provides Analyze local CSV, a color selector and Recolor last chart. A native picker explicitly selects a CSV for local computation. The adapter activates a local analysis context, grants only that operation and target, runs the existing controller in an asyncio worker thread, uses the existing task board, and displays the verified static SVG as a GTK Picture with computed summary and numeric details. No Jan connection, model inference, external network request, shell or audio is needed for this first UI path. SVG decoding uses the system GdkPixbuf/librsvg loader, declared in CI and Debian package dependencies.

The adapter requires an active LOCAL_ONLY profile; explicit deny or ask for filesystem_read/csv_analysis is honored. The chooser acceptance grants the specific analysis operation where no rule exists. Profile activation, conversation end, hard stop and window close invalidate the controller, remove its chart widgets and clear grants. Normal cancellation revokes the pending operation and awaits worker drain; previous artifacts survive. UI callbacks recheck profile identity/version and session epoch before displaying a result. Native chooser ownership is explicit; this is not a claim that the previously reported COSMIC file-picker segfault has been reproduced or fixed.

The worker checks the adapter's memory grants. Out-of-band profile file edits are rechecked on the UI thread at publication and are not a full live OS policy mechanism; worker filesystem access is bounded but not OS sandboxed. Analysis rows are deliberately separate from ordinary chat history, so a future model turn cannot silently disclose the chart or summary. Export/search of analysis artifacts, natural-language typed/voice routing, Piper playback, localized chart axes, and full owner-machine acceptance are still open. Color changes are real deterministic follow-up operations via explicit controls, not proof of natural-language follow-up.

Seven native GTK fixture tests cover chart display without Jan, four chart revisions, hard stop, mode switch, explicit deny, picker cancellation/reopen, and cancellation while the worker is running. The chart test invokes the trusted picker acceptance entry point with a synthetic local path, not a physical interactive picker selection. No owner data is used. CI results must be verified separately, and physical Jan/Whisper/Piper/COSMIC remain HOLD. Do not merge automatically.
