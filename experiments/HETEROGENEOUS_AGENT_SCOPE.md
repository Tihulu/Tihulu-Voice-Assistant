# Heterogeneous agent architecture — experimental scope
Owner request 2026-11-27: agents need not record or control the desktop. Separate role, model, interface, authority, data scope and workspace. Default 1–10 agents, select only necessary roles; no mandatory screen capture.
References: https://openai.github.io/openai-agents-python/agents/ ; https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/magentic-one.html ; https://opencode.ai/docs/agents ; https://code.claude.com/docs/en/sub-agents ; https://reference.langchain.com/python/langgraph-supervisor ; https://docs.crewai.com/ ; https://modelcontextprotocol.io/
Patterns: manager/specialists, router, handoffs, parallel independent tasks, bounded review loops, DAG/workflow, separate workspaces, human approval, checkpoint/resume. Prefer deterministic tools and typed API/IPC/CLI over screen control where equivalent. Browser DOM/accessibility before visual coordinates where possible. Role is not authority; no tool inheritance, no arbitrary model-provided command execution. Cloud advice only, local executor independently checks scope. Screen and input permission separate. Visual markers do not authorize OS input. GUI fallback requires explicit scope and fresh approval, no silent switch. No credential capture. Existing #79 activation HOLD unchanged.
Acceptance: catalog/routing, model capability validation, scoped grants per channel, real public disposable adapter evidence, resource-aware mixed-role scheduling, private data disclosure review, GUI single-input owner and takeover, isolated concurrent workspaces, actual physical owner acceptance. No production activation in this branch.
